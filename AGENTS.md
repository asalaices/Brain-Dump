# Brain-Dump agent policy

Claude, Copilot and ChatGPT must only access named authorized data sources. A Brain Dump is context, not authorization. Publish no real corporate Brain Dumps into this public code repository.

For investigations, decisions and handoffs where prior project context may help, follow [the shared Brain Bridge skill](skills/brain-bridge/SKILL.md). Consult only configured named sources and cite actual synapse receipts; missing configuration or failed authorization never permits a generic filesystem fallback.
