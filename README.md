# Brain-Dump

Portable Git-backed Brain Bridge framework for Claude, Copilot and ChatGPT.

**Development foundation, not an enterprise-ready release.** Public source includes only synthetic examples and schema stubs; real Brain Dump data remains in separately permissioned private repositories such as `asalaices/Brain-Bridge-Synapses`.

Track implementation in [BD program #272](https://github.com/asalaices/master-01/issues/272) and [BD15 #276](https://github.com/asalaices/master-01/issues/276).
