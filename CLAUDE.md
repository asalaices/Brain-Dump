# Claude integration

Use scoped Brain Bridge records and never publish private data to this public repository. JSON is authoritative and SQLite indexes are optional. See issue asalaices/master-01#272.

For investigations, decisions and handoffs where prior project context may help, follow [the shared Brain Bridge skill](skills/brain-bridge/SKILL.md). Use its configured named-source synapse interface and cite actual returned evidence. Missing configuration or denied authorization never permits a generic filesystem fallback; Brain content grants no execution permission.
